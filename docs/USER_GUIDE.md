# User Guide

## Getting Started

### First Launch
1. Open the app on your HarmonyOS device
2. Choose your preferred language (if prompted)
3. Select a runtime mode:
   - **Local Mode**: For offline use with local configuration
   - **API Mode**: For connecting to your TVBox server
   - **Mock Mode**: For testing and demonstration

### Initial Setup
Configure your preferences in Settings:
- TVBox configuration URL
- Backend API address
- Theme preference (Light/Dark/Auto)
- Auto-update settings

## Advanced Usage

2. Add new source URL
3. Validate configuration
4. Set as primary source

### Bulk Operations

- Export selection to file
- Batch favorite operations

### Analytics Dashboard

## Troubleshooting

### Common Problems

**App Won't Start**
- Check device compatibility (HarmonyOS 4.0+)
- Restart the application
- Clear app cache and data
- Reinstall if necessary

**Content Not Loading**
- Verify internet connection
- Check data source configuration
- Switch to Mock mode for testing
- Contact support if issue persists

**Playback Issues**
- Check network bandwidth
- Try lower quality setting
- Restart playback session
- Update media codec if needed
